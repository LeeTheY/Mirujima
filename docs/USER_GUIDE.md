# 미루지마 사용자 가이드

## 1. 처음 시작하기

`npm run build` 후 Chrome의 `chrome://extensions`에서 개발자 모드를 켜고 **압축해제된 확장 프로그램을 로드합니다**를 눌러 `dist` 폴더를 선택하세요. 확장 아이콘을 고정하면 접근하기 편합니다.

첫 실행에서는 다음 순서로 설정합니다.

1. 미루지마 소개 확인
2. Free 또는 Premium 선택
3. Side Panel 또는 Popup 선택
4. 테스트 알림 확인
5. 기본 차단 방식 선택
6. 자리 비움 기준 3분, 5분, 10분 중 선택
7. 첫 일정 만들기 또는 건너뛰기
8. 개인정보 원칙과 사용 흐름 확인

소개 다음에는 멤버십을 선택합니다. **Free로 시작**하거나 건너뛰면 Google 로그인 없이 기존 기능을 그대로 사용합니다. **Premium 선택**을 누른 경우에만 Chrome 기본 Google 계정을 확인하고 Supabase Google 로그인 창을 엽니다. 표시된 Chrome 계정과 로그인 계정이 같아야 하며, 현재 버전은 결제 정보 없이 Premium을 활성화합니다. Settings에서 멤버십을 다시 확인하거나 로그아웃할 수 있습니다.

Side Panel은 계획·리포트까지 자주 볼 때, Popup은 현재 일정과 타이머를 빠르게 조작할 때 적합합니다. 설정에서 언제든 바꿀 수 있습니다.

## 2. 첫 일정 만들기

**Plan → 일정 추가**를 누르고 다음 항목을 입력합니다.

- 일정명과 완료 목표
- 날짜와 목표 집중 시간. 새 일정은 현재 시각의 5분 뒤를 시작으로 잡고 종료 시각을 자동 계산하며, 시작 시각은 직접 조정할 수 있습니다.
- 활동 유형: 입력 작업, 읽기, 시청, 오프라인
- 차단 방식과 사이트 목록
- 권장 휴식 시간

사이트는 `github.com`처럼 입력하면 됩니다. 전체 URL을 붙여도 hostname만 남기고 `www.`를 일관되게 제거합니다. 같은 날짜에 시간이 겹치거나 종료가 시작보다 빠르면 저장되지 않습니다.

## 3. 차단 방식 이해하기

- **Allowlist**: 허용 사이트 외의 일반 http/https 사이트를 모두 차단합니다. 집중이 필요한 작업에 권장합니다.
- **Blocklist**: 등록한 방해 사이트만 차단합니다. 폭넓은 검색이 필요한 작업에 적합합니다.
- **Off**: 사이트 차단 없이 타이머와 기록만 사용합니다.

서브도메인은 기본으로 함께 처리합니다. `docs.example.com`은 `example.com` 규칙에 포함됩니다.

## 4. 집중 시작과 종료

Today 또는 Plan에서 **집중 시작**을 누르세요. 활성 세션이 저장되고 종료·상태 확인 alarm과 차단 규칙이 구성됩니다. Focus에서는 다음 동작을 할 수 있습니다.

- 일시정지: 타이머와 차단 해제
- 휴식 시작: 집중 타이머와 차단을 멈추고 휴식 시간을 별도로 측정. 권장 시간을 넘기면 `+시간`으로 계속 누적
- 재개: 타이머와 차단 복구
- 완료: 완료 기록과 리포트 반영
- 미완료로 종료: 미완료 기록과 리포트 반영

휴식 버튼은 언제든 누를 수 있습니다. 일정의 권장 휴식 시간은 강제 제한이 아니라 알림 기준이며, 초과해도 휴식 시간은 계속 측정됩니다. 집중으로 돌아오거나 세션을 끝내면 실제 휴식 시간이 확정되어 리포트에 반영됩니다.

목표 시간이 끝나면 타이머, 차단, 상태 확인이 멈추고 **완료/미완료 결과 선택 화면**이 유지됩니다. 완료 또는 미완료를 선택한 뒤 확인 단계에서 확정해야 기록에 반영됩니다. 시스템 알림에서 선택해도 별도의 확정 알림을 한 번 더 거칩니다. 타이머는 매초 storage에 쓰지 않고 시작 시각과 누적 시간으로 계산합니다.

## 5. 차단 페이지와 임시 허용

집중 중 미허용 사이트를 열면 미루지마 차단 페이지로 이동합니다. 현재 일정, 남은 시간, 허용 사이트를 확인하고 이전 페이지나 집중 화면으로 돌아갈 수 있습니다.

꼭 필요한 경우 1분, 5분, 이번 세션 중 하나를 선택하고 이유를 남겨 임시 허용하세요. hostname, 이유, 시간만 기록되고 만료 후 차단 규칙이 자동 복구됩니다.

## 6. 상태 확인 알림

미루지마는 다음 신호를 함께 봅니다.

- Chrome의 `idle` 상태
- 활성 탭 hostname과 허용 여부
- 페이지가 보이는지 여부
- 클릭·키 입력·스크롤·pointer 활동의 마지막 발생 시각
- 최근 반복 차단 시도

집중 중 1분마다 검사하며, 입력 작업은 5분, 읽기는 15분, 영상은 45분 동안 Chrome 활동 신호가 없을 때 확인합니다. 오프라인 작업은 Chrome 활동량을 판단에서 제외합니다. 자리 비움은 설정한 3·5·10분 동안 시스템의 키보드·마우스 입력이 없거나 화면이 잠긴 경우입니다.

입력한 글자, 클릭한 요소의 텍스트, 페이지 본문은 수집하지 않습니다. Chrome 밖 앱의 사용 내용은 알 수 없습니다.

알림은 시스템 알림, 확장 아이콘 배지, 앱 내부 경고, 차단 페이지로 보완됩니다. 오늘 화면의 **확인할 알림**에는 제목, 내용, 시각과 확인·이동·결과 선택 버튼이 남습니다. 알림이 보이지 않으면 설정의 **알림 테스트**를 실행하고 Chrome 및 macOS/Windows의 Chrome 알림 권한을 확인하세요.

## 7. 미루기와 리포트

일정 알림이나 Today에서 **5분 미루기**를 선택할 수 있습니다. 3회 이상이면 누적 미루기를 강하게 안내하며 횟수는 리포트에 포함됩니다.

Reports에는 최근 30일의 다음 항목이 표시됩니다.

- 일정 달성률과 집중 시간 달성률
- 목표/실제 집중 시간
- 미루기와 차단 시도
- 자리 비움 시간
- 실제 휴식 시간
- 가장 집중한 일정과 다음 날을 위한 로컬 요약

리포트는 날짜가 바뀌거나 다음 실행 시 다시 생성해도 같은 날짜 기록을 갱신하는 방식으로 동작합니다.

Premium은 Reports 상단에서 월간 학습 잔디를 확인할 수 있습니다. 실제 집중 시간과 완료 일정 수로 일별 점수와 0~4 강도를 계산하며, 날짜를 누르면 상세 집계를 표시합니다. Today에는 오늘까지 이어진 연속 학습 일수가 표시됩니다. 단순 앱 실행이나 클릭만으로 잔디가 생기지 않습니다.

## 8. 설정과 데이터 관리

설정에서 주 UI, 기본 차단 모드, 자리 비움 기준, 알림, 최소 활동 신호, 일일 리포트를 변경할 수 있습니다. **JSON 내보내기**는 원본 데이터를 백업하거나 개발 점검에 쓰는 파일이며, 현재 다시 가져오기나 표 변환 기능은 제공하지 않습니다.

Premium 로그인 후 **클라우드 동기화** 카드에서 최초 방향을 반드시 선택합니다.

- **이 기기 기록 백업**: 현재 일정·설정·완료 세션·리포트·학습 집계를 클라우드에 올립니다.
- **클라우드 기록 복원**: 먼저 항목 수를 미리 보고, 확인한 뒤 이 기기 기록과 병합합니다.
- 초기 설정 후에는 15분 주기와 **지금 동기화**로 여러 PC의 변경을 반영합니다.
- 오프라인 변경은 대기열에 남고 다음 연결 때 재시도합니다.
- 같은 항목이 두 PC에서 수정되면 동기화 카드에서 이 기기 또는 클라우드 버전을 선택합니다.

Premium 구조화 기록은 최대 365일 보관하지만 heartbeat 원본과 탭 그룹 snapshot은 전송하지 않습니다. 동기화 실패가 나도 로컬 일정과 집중 기능은 계속 동작합니다.

**전체 기록 초기화**는 확인 후 일정, 세션, 이벤트, 리포트와 설정을 지우고 기본 온보딩 상태로 돌아갑니다. 삭제된 로컬 데이터는 미루지마에서 복구할 수 없습니다.

## 9. 화면 OCR·문법 교정·핵심 요약·학습 정리 (Premium)

Side Panel 상단의 **화면 AI 도구**를 누릅니다. Popup을 주 UI로 쓰는 경우 Popup 하단에서 Side Panel을 먼저 여세요.

1. 분석할 일반 웹페이지를 활성화하고 **화면 영역으로 내용 가져오기**를 누릅니다.
2. 현재 탭 위에서 글이 보이는 사각형 영역을 드래그합니다. Esc 또는 취소 버튼으로 중단할 수 있습니다.
3. crop된 전송 이미지를 확인하고 문법 교정, 핵심 요약, 학습 정리 중 결과 방식을 선택합니다. 민감 정보가 있으면 다시 선택하세요.
4. 동의 후 Qwen OCR을 실행합니다. 문단·표·목록이 `b1`, `b2` 같은 block으로 나뉘며 각 원문을 직접 검토할 수 있습니다.
5. 문법 교정은 맞춤법만·자연스러운 윤문·간결한 윤문 결과와 diff를 제공합니다.
6. 핵심 요약은 한 문장 주제, 중요 내용 3~5개, 짧은 요약과 불확실한 항목을 제공합니다.
7. 학습 정리는 핵심 개념, 설명, 용어·정의, 기억할 내용과 추가 확인 항목을 구조화합니다.
8. 요약·학습 정리의 근거 버튼을 누르면 해당 OCR block으로 이동합니다. 반드시 원문과 대조하세요.
9. 결과를 복사할 수 있으며, 문법 교정은 화면 선택 전에 활성화한 일반 입력창에 적용할 수 있습니다.

AI 요약은 중요한 문맥을 누락하거나 잘못 판단할 수 있으며 의료·법률·재무 판단의 단독 근거로 사용하면 안 됩니다. Google Docs, Notion, CodeMirror 등 복잡한 편집기는 직접 적용을 보장하지 않습니다. 현재 visible viewport만 지원하고 전체 페이지 자동 이어붙이기는 하지 않습니다. 이미지·OCR 원문·결과는 기본 저장되지 않으며 AI 실패가 일정·집중 기능을 막지 않습니다.

## 10. 지원 범위

일반 http/https 페이지를 지원합니다. `chrome://`, Chrome Web Store 같은 제한 페이지, 다른 브라우저, Chrome 밖 앱은 차단하거나 상세 활동을 확인할 수 없습니다. 운영체제가 Chrome 알림을 차단한 경우 시스템 알림도 강제로 표시할 수 없습니다.

## 11. 스마트 탭 그룹화

- 집중 시작·재개 시 현재 창의 일반 웹 탭을 자동 정리합니다.
- 일정의 허용 사이트는 `🎯 현재 작업`에 최우선 배치합니다. 휴식 중 연 Netflix도 해당 일정에서 허용했다면 작업으로 분류됩니다.
- 고정 탭과 사용자가 만든 Chrome 그룹은 기본적으로 보존합니다.
- Focus의 **지금 탭 정리**, **정리 전 상태 복원**, **현재 작업 세트로 저장**을 사용할 수 있습니다. Popup에는 활성 세션 중 축약형 **탭 정리** 버튼만 표시됩니다.
- `📦 분류 필요`가 있으면 분류와 기억 범위를 선택할 수 있습니다. `이번에만`, `이 일정에서 기억`, `항상 기억`을 지원합니다.
- Settings에서 자동 실행, 실시간 새 탭 분류, 기존 그룹·고정 탭 처리, 종료 시 복원 정책을 바꿀 수 있습니다.

미루지마는 탭을 자동으로 닫지 않습니다. 복원할 때 집중 중 닫은 탭을 다시 열거나 새로 연 탭을 닫지 않으며, 남아 있는 탭의 순서·고정·기존 그룹만 가능한 범위에서 복원합니다.
