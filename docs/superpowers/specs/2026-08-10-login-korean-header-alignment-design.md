# 로그인 화면 한글화·공개 헤더 정렬 및 멤버십 상태 구분 설계

## 목표

- 로그인 화면의 주요 영문 표기 세 곳을 자연스러운 한글로 변경한다.
- 첫 페이지(`/`)와 로그인 화면(`/login`)의 미루지마 로고를 동일한 위치에 표시한다.
- 학생과 보호자 마이페이지에서 실제 멤버십 상태를 명확히 구분한다.

## 문구

| 기존 | 변경 |
| --- | --- |
| `WELCOME TO MIRUJIMA` | `미루지마에 오신 것을 환영합니다` |
| `GOOGLE AUTHENTICATION` | `구글 계정 인증` |
| `Mirujima 계정 로그인` | `미루지마 계정 로그인` |

로그인 방식과 서비스 이름을 설명하는 본문의 `Google`, `Chrome`, `Supabase` 제품명은 고유명사이므로 유지한다.

## 레이아웃

로그인 화면의 별도 `onboarding-header` 규격을 제거하고 첫 페이지에서 사용하는 `public-header` 클래스를 그대로 재사용한다. 두 화면은 `max-width: 1220px`, 높이 `78px`, 좌우 패딩 `24px`이라는 동일한 헤더 기준을 공유한다.

로그인 본문 카드와 반응형 구조는 변경하지 않는다. 모바일에서는 기존 `public-header` 미디어 규칙을 함께 적용해 로고 좌우 여백도 동일하게 유지한다.

## 멤버십 상태

학생과 보호자 화면은 동일한 멤버십 상태 모델을 사용한다. `memberships.plan = 'premium'`, `status = 'active'`이고 이용 종료일이 없거나 현재보다 이후일 때만 Premium 활성 상태로 판단한다. 데이터가 없거나 조건을 만족하지 않으면 무료 상태로 표시한다.

### 무료 상태

- 배지: `무료 플랜`
- 제목: `미루지마 기본 서비스 이용 중`
- 설명: `Premium 멤버십에 가입하지 않은 상태입니다. 기본 기능은 계속 이용할 수 있습니다.`
- 버튼: `Premium 혜택 알아보기`

### Premium 활성 상태

- 배지: `Premium 이용 중`
- 제목: `미루지마 Premium 활성화`
- 설명: `AI 요약과 Premium 분석 기능을 이용할 수 있습니다.`
- 이용 종료일이 있으면 한국어 날짜로 표시한다.
- 버튼: `멤버십 관리`

멤버십은 서버에서 현재 로그인 사용자의 행만 조회한다. 학생과 보호자 카드가 같은 판정 함수와 표시 문구를 사용하도록 공통 모델을 두되, 기존 카드 레이아웃과 역할별 주변 기능은 유지한다.

## 검증

- `/`와 `/login`을 동일한 데스크톱 뷰포트에서 열어 로고의 왼쪽·위쪽 위치가 일치하는지 확인한다.
- `/login`에서 세 영문 표기가 모두 한글로 변경됐는지 확인한다.
- 무료·Premium·만료 상태 판정 테스트를 추가한다.
- 학생과 보호자 화면에 동일한 상태 문구와 배지가 표시되는지 확인한다.
- 모바일 뷰포트에서 헤더와 본문이 겹치거나 잘리지 않는지 확인한다.
- 관련 타입 검사와 렌더링 콘솔 오류 검사를 통과한다.
