# Mirujima v3 Phase 0-4 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 기존 Extension을 보존하면서 실행 가능한 Next.js Web/PWA, Supabase 역할·가족 연결, Web 집중 계획과 안전한 Extension bridge를 구현한다.

**Architecture:** Extension은 저장소 루트에 유지하고 `apps/web`과 `packages/contracts`를 추가한다. Web은 Supabase canonical schedule/session을 만들고 Extension은 direct message 또는 periodic resync를 계기로 서버 소유권을 재검증한 뒤 기존 DNR·alarm·storage 엔진을 실행한다.

**Tech Stack:** Next.js App Router, React, TypeScript strict, native CSS, Supabase SSR/JS, Zod, Vitest, Playwright, Chrome Extension Manifest V3, PostgreSQL RLS/RPC

## Global Constraints

- `AGENTS.md` v3가 Source of Truth다.
- 기존 Extension의 Popup, Side Panel, focus, DNR, alarm, notification, recovery, cloud sync와 Premium 동작을 보존한다.
- `cloud_schedules.payload`와 `cloud_focus_sessions.payload`를 재사용한다.
- 신규 업무 테이블은 `family_links` 하나만 추가한다.
- Wallet, Toss, 실제 포인트 이동·정산, AI, 전체 기록 dashboard와 Push 알림은 구현하지 않는다.
- production remote Supabase에는 쓰지 않는다.
- 새 production code는 실패하는 테스트를 먼저 확인한다.
- 사용자가 수정한 `AGENTS.md`와 `supabase/.temp/`를 stage하거나 변경하지 않는다.
